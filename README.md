# rfid-enterprise-system

"RFID enterprise system" is a Full-Stack project that implements a comprehensive access control system. It utilizes an Arduino UNO as an edge device for reading physical RFID tags, while all access verification, event logging and management logic take place on a PC Backend.

### 🎯 Main objectives
- **Database Structure** Relational data structure supporting division into roles with selective access.
- **Edge Layer Construction** RFID key reading with physical feedback
- **Backend Integration** Computing the logic and connection between edge layer and database
- **Frontend UI** Console for security monitoring and access management
